# Red_Cafeteria_Unicornio
## Descripcion
la verdad es que tal y como el otro este es un proyecto de escentado, pero almenos me sirve la experiencia para mi curriculumel proyecto esta enfocado en crea una red para una cafeteria, las instrucciones estaran en la bitacoa pero en resumen, solo es una red cencilla de 2 redes diferentes, una de clientes y otra de empleados, con DHCP configurado y que no se pueda hacer ping entre las redes.

## Detalles
en si la red es cencilla, solo es hacr 2 redes separadas con sus respectivos equipos cada una, ademas de esto configure una tele, por ultimo me gustaria agregar que se me paso hacer la bitácora, asi que al menos la primera parte de la fecha y un montón de datos, sera mayormente a memoria mia
<br>
En si es un proyecto de cisco paquet tracer, asi que no hay mucho que decir, se corre como ya sabe y lo sunico que dire es que puede dar algo de lag, pero no mucho
